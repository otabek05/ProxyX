Issue & renew Let's Encrypt certificates with certbot. The proxy answers the HTTP-01 challenge on port 80 itself (--webroot), so there is no downtime. The domain must resolve to this server and port 80 must be reachable from the internet. On success the cert paths are written into the config and the proxy reloads.
